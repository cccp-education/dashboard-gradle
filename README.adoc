= dashboard-gradle 🟡

N3 Gradle plugin for visualizing workspace vision and progress.

== Structure

[source]
----
dashboard-gradle/
├── dashboard-plugin/        # Gradle plugin (independent build)
│   ├── AGENT.adoc           # Absolute rules
│   ├── .agents/             # Agent governance
│   ├── src/                 # Kotlin source code
│   └── build.gradle.kts     # java-gradle-plugin
├── build.gradle.kts         # Root consumer (dogfood)
├── settings.gradle.kts      # Root settings
└── gradle/                  # Wrapper + catalog
----

== Prerequisites

- JDK 25+
- Gradle 9.9+

== Development

[source,shell]
----
# Build the plugin
cd dashboard-plugin && ./gradlew publishToMavenLocal -Pversion=0.0.5

# Exercise it from the root (crawls ../.. = foundry/)
cd .. && ./gradlew generateDashboard
----

The crawled directory is configurable:

[source,shell]
----
./gradlew generateDashboard -Pdashboard.configPath=/path/to/foundry
./gradlew generateDashboard -Pdashboard.workspaceBacklog=/path/to/BACKLOG.adoc
----

`workspaceBacklog` (default `../../../BACKLOG.adoc`) adds the workspace GBL
EPICs to the pivot under the synthetic `Transverse` borough.

== Tasks

- `crawlDashboard` — crawls every `INDEX.adoc` / `SESSIONS_HISTORY.adoc` /
  `BACKLOG.adoc` of the workspace (build outputs, caches and backups pruned),
  parses the workspace `BACKLOG.adoc`, and writes
  `build/dashboard-data/dashboard-data.json` (`schemaVersion: "1.0"` +
  point-based `progress`, global and per borough). Incremental (``)
- `generateDashboard` — renders the Panorama (`index.html`) + one
  `borough-<slug>.html` sheet per borough, offline assets, and the JBake site
- `publishDashboardSite` — copies the generated JBake-compatible site to
  `build/dashboard-publish`
- `serve` — serves the generated site locally on `http://localhost:8820`
  (`-Pdashboard.serveHost` / `-Pdashboard.servePort`)

== Rendering

- Global progress (points done/total) + the MVP0 A1→A4 vision (DSL
  `dashboard { criticalPath { … } }`) + per-borough progress bars and sheets.
- EPIC matrix grouped by borough, activity stream (60 most recent sessions,
  full set in the JSON pivot), DAG layers as a static `N0 → N4` table
  (interactive graph belongs to Brooklin Flow), MVP0 timeline.
- No CDN: Bootstrap 5.3.3 is vendored (`src/main/resources/static/vendor/`),
  the page renders fully offline.
- `src/main/resources/prototype/` is a throwaway Phase 0 UX prototype (pure
  HTML/CSS/JS/mock), excluded from the JAR and never published.

== Testing

[source,shell]
----
./gradlew test          # unit + functional tests
./gradlew cucumberTest  # BDD scenarios
./gradlew check         # everything
----

Local policy: build/compile only (`compileKotlin`, `compileTestKotlin`);
test suites run in CI.
