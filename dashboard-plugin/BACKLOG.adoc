== DSH-9 — Serveur local `serve` + qualité du rendu (demande pilote S-220, 2026-11-14)

_Constat pilote_ : `./gradlew serve` **n'existe pas** — le plugin n'expose que
`crawlDashboard`, `generateDashboard`, `publishDashboardSite` — et le rendu
produit dans `build/dashboard/index.html` est jugé inexploitable.

_Faits mesurés (S-220)_ :

* `build/dashboard/index.html` **est bien** la sortie de `generateDashboard`
  (`DashboardRenderer`, statique) ; fichier daté du 2026-09-21 (**stale**) et
  en-tête « **2 boroughs — 12 epics** » alors que le workspace gouverne 30+
  boroughs.
* Cause probable : le root consommateur configure `configPath =
  "dashboard-plugin"` (le plugin lui-même) au lieu de la racine workspace
  (`foundry/`) → le crawl ne voit qu'un sous-ensemble (cf. DSH-BOUNDARY-2).
* Dépendance réseau : Bootstrap chargé depuis `cdn.jsdelivr.net` (rendu non
  offline, aucun asset vendoré).

=== US DSH-9.1 — Tâche `serve` (serveur local) — 3 pts — ✅ S-220

* Tâche `serve` (groupe `dashboard`), `dependsOn generateDashboard`.
* Serveur HTTP embarqué JDK (`com.sun.net.httpserver.HttpServer`), **aucune
  dépendance externe** ; bind **127.0.0.1** uniquement.
* Sert `outputDir` en statique (`/` → `index.html`), MIME corrects.
* Port/host configurables : extension `serve { host; port }` +
  `-Pdashboard.servePort` (défaut 8080, échec explicite si occupé).
* Tâche bloquante, message `Serving <outputDir> on http://127.0.0.1:<port>
  (Ctrl+C to stop)` ; compatible `./gradlew -t serve` (régénération continue).
* Tests : unit (résolution port/MIME), functional TestKit (démarrage/arrêt),
  Cucumber BDD.

=== US DSH-9.2 — Audit + correction du rendu `generateDashboard` — 5 pts — ✅ S-223

* Corriger la source de données : `configPath` → racine workspace ; crawl de
  **tous** les boroughs (INDEX + BACKLOG + SESSIONS_HISTORY).
* Rendu vérifié : EPIC matrix, activity stream, DAG lisibles ; états vides.
* Zéro CDN : assets vendorés (CSS local), rendu offline.
* Preuve : capture(s) + `dashboard-data.json` (N boroughs) ; test de
  non-régression sur le nombre de boroughs/EPICs.

=== Critères d'acceptation

* `./gradlew serve` sert `build/dashboard/index.html` sur `localhost:8820` (défaut).
* `generateDashboard` produit un dashboard dont l'en-tête reflète le workspace
  complet (pas « 2 boroughs »), sans dépendance réseau.
